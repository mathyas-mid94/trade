# Tunnel de Fin de Carrière — simulateur interne

Outil de conseil **hors ligne** : ouvrir `index.html` dans un navigateur (double-clic). Aucun serveur,
aucune librairie externe, aucune donnée envoyée. Les dossiers clients s'enregistrent en `.json`
(bouton « Enregistrer ») et se rouvrent avec « Ouvrir un dossier ». « Imprimer / PDF » produit la
synthèse client sans le panneau de saisie.

Blocs : saisie du profil → moteur (carence, durée ARE, trimestres jour par jour, rétroplanning de la
date de rupture) → comparatif de sortie du PER + bilan global vs maintien en poste + points de vigilance.

Les paramètres réglementaires (PASS, ARE, diviseur du différé, barème IR, âges…) sont éditables dans
« Paramètres réglementaires » : à revalider avant chaque rendez-vous.
